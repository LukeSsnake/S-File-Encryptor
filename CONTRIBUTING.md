## Contributing to S File Encryptor

Thank you for your interest in contributing to S File Encryptor!

S File Encryptor is a free and open-source Android application for encrypting and decrypting files locally on the device.

# How to Contribute

Contributions are welcome, including bug fixes, security improvements, documentation updates, and usability enhancements.

# Reporting Bugs

When reporting a bug, please include:

- A clear description of the issue.
- Steps to reproduce it.
- Your Android version and device model.
- Relevant error messages or logs, with personal information removed.

Never share passwords or sensitive files in bug reports.

# Development Setup

1. Install JDK 17 and the Android SDK.

2. Clone this repository.

3. Open the project in Android Studio or use the Gradle wrapper from the project root.

4. Build the debug version with:
   
   ./gradlew assembleDebug

On Windows, use "gradlew.bat assembleDebug".

# Submitting Changes

1. Fork the repository.
2. Create a branch for your changes.
3. Make focused changes that are easy to review.
4. Build the application and test the affected functionality.
5. Submit a pull request describing the changes and how they were tested.

# Security

Security-related issues should be reported responsibly. Do not publish passwords, private keys, or sensitive user data in issues or pull requests.
